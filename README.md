# Pranay Singh — Academic & Industry Research Portfolio

A static personal website designed for GitHub Pages and tailored for post-PhD academic and industry job searches.

## Publish on GitHub Pages

1. Create a repository, for example `pranaysingh.github.io` or `portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `CV-Pranay-Singh.pdf` to the repository root.
3. In GitHub, go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.

## Before publishing

Search `index.html` and add your real URLs for:
- Google Scholar
- LinkedIn
- ORCID
- GitHub

You may also want to add:
- Advisor / dissertation title
- Expected defense date
- Current working papers / manuscripts under review
- Teaching experience and teaching statement for faculty applications
- Research statement PDF
- Professional engineering licensure information, if applicable

The included CV is named `CV-Pranay-Singh.pdf` so the website download button works immediately.
